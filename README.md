## Функции потерь

Функция потерь показывает, насколько предсказания модели отличаются от истинных значений. При обучении модель минимизирует эту ошибку, двигаясь против градиента.

### `BaseLoss`

Базовый класс задаёт общий интерфейс функций потерь:

- `error(y_true, y_pred)` возвращает вектор ошибок `y_pred - y_true`;
- `value(y_true, y_pred)` вычисляет значение функции потерь;
- `gradient(y_true, y_pred)` вычисляет градиент по предсказаниям `dL/dy_pred`.

Методы `value` и `gradient` реализуются в дочерних классах.

### `MSE`

Средняя квадратичная ошибка:

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2
$$

Сильнее штрафует большие ошибки за счёт возведения в квадрат. Градиент:

$$
\frac{\partial MSE}{\partial \hat{y}_i} = \frac{2(\hat{y}_i-y_i)}{n}
$$

### `MAE`

Средняя абсолютная ошибка:

$$
MAE = \frac{1}{n}\sum_{i=1}^{n}|\hat{y}_i-y_i|
$$

Соответствует среднему манхэттенскому расстоянию между истинными и предсказанными значениями. Градиент:

$$
\frac{\partial MAE}{\partial \hat{y}_i} = \frac{sign(\hat{y}_i-y_i)}{n}
$$

### `RMSE`

Корень из средней квадратичной ошибки:

$$
RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2}
$$

Выражается в тех же единицах, что и целевая переменная. Градиент:

$$
\frac{\partial RMSE}{\partial \hat{y}_i} = \frac{\hat{y}_i-y_i}{n \cdot RMSE}
$$

Если `RMSE = 0`, класс возвращает нулевой градиент.

## Метрики

Метрики оценивают качество уже полученных предсказаний и не обязательно используются для обучения модели.

### `BaseMetric`

Базовый класс задаёт метод `score(y_true, y_pred)`. Конкретная метрика должна реализовать его и вернуть числовую оценку качества.

### `R2`

Коэффициент детерминации сравнивает модель с базовым прогнозом, равным среднему значению целевой переменной:

$$
R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}{\sum_{i=1}^{n}(y_i-\bar{y})^2}
$$

- `R2 = 1` - предсказания полностью совпадают с истинными значениями;
- `R2 = 0` - модель работает как прогноз средним значением;
- `R2 < 0` - модель работает хуже прогноза средним значением.

Методы `value` и `score` возвращают одно значение. Если все истинные значения одинаковы, текущая реализация возвращает `1.0`.

## Модели

### `BaseModel`

Базовый класс задаёт общий интерфейс моделей:

- `fit(X, y)` обучает модель;
- `predict(X)` строит предсказания;
- `score(X, y)` оценивает качество модели.

Все три метода реализуются в дочерних классах.

### `LinearRegression`

Линейная регрессия предсказывает непрерывное значение как линейную комбинацию признаков:

$$
\hat{y} = Xw + b
$$

Класс обучает веса пакетным градиентным спуском: на каждой эпохе градиент рассчитывается по всей обучающей выборке, после чего параметры обновляются в направлении уменьшения ошибки.

Параметры класса:

- `learning_rate` - шаг обновления весов;
- `epochs` - число итераций обучения;
- `l1` - коэффициент L1-регуляризации, способной занулять слабые веса;
- `l2` - коэффициент L2-регуляризации, уменьшающей значения весов.

Свободный коэффициент хранится в `coefficients_[0]`, веса признаков - в остальных элементах. Регуляризация к свободному коэффициенту не применяется. Значение функции потерь с регуляризацией после каждой эпохи записывается в `history_`.

Методы класса:

- `fit(X, y, loss_function)` обучает коэффициенты;
- `predict(X)` возвращает `Xw + b`;
- `score(X, y, loss_function)` возвращает значение переданной функции оценки.

В текущей реализации `loss_function` в методе `fit` используется для заполнения `history_`, а градиент весов рассчитывается по квадратичной ошибке.
